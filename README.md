# GREEN-API Chat

MVP чата на React + TypeScript + Tailwind CSS для отправки и получения текстовых сообщений через GREEN-API.

## Запуск Dev-версии

```bash
npm i
npm run dev
```

Откройте адрес, который покажет Vite, перейдите на страницу авторизации и введите `API URL`, `idInstance` и `apiTokenInstance`. После успешной проверки GREEN-API параметры сохраняются в `localStorage`.

## Настройка GREEN-API

Для режима HTTP API у инстанса должен быть пустой `webhookUrl`, а уведомления о входящих сообщениях должны быть включены. Приложение получает уведомления через `receiveNotification`, после обработки удаляет их через `deleteNotification`.

`receiveNotification` возвращает `null`, если за `receiveTimeout` (от 5 до 60 секунд) в очереди нет нового уведомления. Это штатный ответ, а не ошибка. Открытый чат дополнительно опрашивает `getChatHistory`, поэтому сообщения появляются и при пустой очереди уведомлений. Если уведомления нужны в реальном времени, проверьте в настройках инстанса: `webhookUrl` пустой, `incomingWebhook` установлен в `yes`; для исходящих сообщений также включите соответствующие `outgoing*Webhook`.

MVP поддерживает только текстовые сообщения. Список чатов и история загружаются из API при открытии приложения и выборе чата. В браузере сохраняются только `API URL`, `idInstance` и `apiTokenInstance` после успешной авторизации.
